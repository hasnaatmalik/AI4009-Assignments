This repository contains the deliverables for **Assignment 3: Generative AI Systems** (Spring 2026), focusing on deep generative models including **DCGAN**, **WGAN-GP**, **Pix2Pix**, and **CycleGAN**.

---

## 📁 Directory Structure

| Directory | Description |
| :--- | :--- |
| 🖼️ **`q1-dcgan-wgangp/`** | Contains Kaggle notebooks for training DCGAN and WGAN-GP on Pokemon/Anime datasets, plus a Mac MPS-optimized Gradio app for inference. |
| ✏️ **`q2-pix2pix/`** | Contains the notebook for paired Sketch-to-Photo translation using a U-Net Generator and PatchGAN Discriminator, alongside an inference app. |
| 🔄 **`q3-cyclegan/`** | Contains the notebook for unpaired Domain A <-> Domain B translation using ResNet Generators and LSGAN Discriminators, alongside a bidirectional inference app. |

---

## 💻 Hardware & Training

All training scripts are designed for **Kaggle (GPU T4 x2)**, heavily relying on:
*   `torch.cuda.amp` for Mixed Precision Training.
*   `torch.nn.DataParallel` for parallelizing generator and discriminator models across multiple GPUs.
*   Comprehensive loss monitoring, model checkpointing every 5-10 epochs, and automated image grid generation.

---

## 🚀 Inference Apps (Apple Silicon MPS Supported)

Each subfolder contains an `app.py` built with **Gradio** for interactive testing. These apps are specifically configured to run explicitly on the **Mac `mps` backend** (with fallbacks to `cuda` or `cpu`). 

### How to Run:
1. Ensure your environment is set up and matches the root `requirements.txt`.
2. Place the trained `.pth` checkpoint files (generated by the notebooks on Kaggle) into the respective `qX` directory.
3. Navigate to the desired folder and run the app:
   ```bash
   cd q1-dcgan-wgangp
   python3 app.py
   ```
4. Open the local web UI provided in the terminal to test translations or generations!
